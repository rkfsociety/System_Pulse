# Память проекта

## confirmed

- Проект представляет собой Windows-оверлей мониторинга ресурсов на PyQt6: `overlay.py` показывает CPU, RAM, GPU, VRAM и сетевой трафик.
- VBS-скрипты запускают `pythonw.exe` из локального `.venv\Scripts` рядом со скриптом; путь вычисляется относительно папки скрипта.
- Зависимости: `PyQt6`, `psutil`, `nvidia-ml-py` (предоставляет модуль `pynvml`).
- `watchdog_overlay.vbs` запускает приложение при отсутствии процесса.
- Автозапуск при входе в Windows включается через пункт меню трея и хранится в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` под именем `SystemPulse`; запись запускает `start_overlay.vbs`.
- `overlay.py` защищён именованным mutex `Local\\WnoutOverlaySingleton`; одновременно допускается только один экземпляр.
- В меню трея есть переключатель `Разрешить перемещение`. В выключенном состоянии окно click-through; во включённом состоянии его можно перетаскивать левой кнопкой мыши.
- Пункт `Показывать оверлей` в меню трея скрывает и повторно показывает панель.
- В меню трея пункт `Переместить оверлей` временно включает перемещение; при потере фокуса режим отключается автоматически.
- Позиция сохраняется в `settings.json` рядом с `overlay.py`; `x`/`y` задают запасную позицию, `window_positions` хранит смещения точных окон, а `application_positions` — запасные смещения по приложению для окон с изменившимся заголовком.
- Ошибки и проблемы сохранения настроек записываются в `overlay.log` рядом с `overlay.py`.
- При закрытии оверлей вызывает `pynvml.nvmlShutdown()`.
- Пункт выхода в трее называется `Выход`.
- В оверлее есть строка `UPTIME`, показывающая время работы Windows-устройства с момента загрузки ОС в формате `Nд 00ч 00м` (дни, часы, минуты).

## verified_checks

- Синтаксис `overlay.py` проверяется через `ast.parse`.
- Импорт `PyQt6`, `psutil` и `pynvml` успешно проверен.
- После запуска должен существовать ровно один экземпляр оверлея; именованный mutex в `overlay.py` блокирует дубликаты.
